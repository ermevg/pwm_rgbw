# Драйвер для управления ШИМ RGBW контроллером

## Описание проекта
Программный модуль (драйвер) для управления многоканальным ШИМ-контроллером светодиодов RGBW по интерфейсу I2C. Реализован на языке C (стандарт C99) для микроконтроллеров семейства ARM Cortex-M. Драйвер обеспечивает инициализацию устройства, управление яркостью и состоянием отдельных каналов, а также установку цвета в формате RGB. Исходные файлы драйвера расположены в каталоге drivers.

## Инструкция по сборке и запуску
Разработка велась в операционной системе Linux (Debian) в текстовом редакторе Visual Studio Code.

### Необходимые инструменты
- Компилятор: GCC (arm-none-eabi-gcc - обязательно)
- Стандарт: С99
- Система сборки: Make (обязательно)
- Текстовый редактор: VSCode
- OpenOCD (опционально, необязательно для обычной сборки проекта, только для прошивки и отладки)
- gdb-multiarch (опционально, необязательно для сборки проекта, только для отладки)


### Сборка
Откройте скачанный проект в Visual Studio Code.
Написанный Makefile предоставляет возможность выполнить 2 варианта сборки - Debug и Release.
Для сборки в одном из этих вариантов в терминале выполните:
```bash
make debug
make release
```
После этого в директории проекта появятся папка с объектными файлами obj и папка build с готовой прошивкой в формате .elf/.bin.
Для очистки проекта от этих папок достаточно выполнить:
```bash
make clean
```
Также есть возможность выполнить быструю прошивку МК командой:
```bash
make flash
```
Однако использовать эту команду не нужно, используйте только debug или release для сборки.

Для удобства можете установить расширение Task Buttons для VSCode и в нижней панели появятся значки, нажав на которые, будут выполняться действия описанные выше.

## Пример использования API

### Инициализация контроллера 
```c
    #include "rgbw_driver.h"
    /*Инициализация I2C интерфейса - 1 модуль(канал), частота 400 кГц*/
    if(I2C_Init(I2C_CH0, I2C_FREQ_400_KHZ) != I2C_ERR_SUCCESS)
    {
        while(1); // В случае ошибки уходим в цикл
    }
        
    /*Инициализация RGBW контроллера*/
    if(RGBW_Init(I2C_CH0) != RGBW_ERR_SUCCESS)
    {
        while(1);
    }
```

### Установка цвета RGB
```c
   /*Пример установки цвета RGB - 255, 128, 0 - Оранжевый*/
    if(RGBW_Set_RGB_Color(I2C_CH0, FULL_BRIGHTNESS, HALF_BRIGHTNESS, OFF_BRIGHTNESS) != RGBW_ERR_SUCCESS)
    {
        while(1);
    }
```

### Управление яркостью 
```c
    /*Пример установки канала D4 на половину яркости*/
    if(RGBW_SetBrightness(I2C_CH0, RGBW_CH_D4, HALF_BRIGHTNESS) != RGBW_ERR_SUCCESS)
    {
        while(1);
    }
```

### Отключить все каналы
```c
    /*Пример выключения всех каналов*/
    if(RGBW_SetAllLed(I2C_CH0, CH_OFF) != RGBW_ERR_SUCCESS)
    {
        while(1);
    }
```
